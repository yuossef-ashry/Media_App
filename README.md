# 🩵 Social Media App

A social media web application developed as part of my **Front-End Development journey at Route Academy**. The project focuses on building an interactive platform where users can manage their accounts, create posts, and interact through comments.

## 📌 Project Overview

The goal of this project is to build a social media platform with essential user authentication, profile management, and post and comment operations while working with the provided API.

The application is designed to provide a structured user experience, from creating an account and logging in to managing posts and interacting with other users' content.

## ✨ Core Features

### 🔐 Authentication

- User sign-up.
- User login.
- Change account password.

### 🏠 Posts & Feed

- Home page displaying posts.
- Create new posts.
- Update existing posts.
- Delete posts.
- View post details.

### 💬 Comments

- Display comments on individual posts.
- Create comments.
- Update existing comments.
- Delete comments.

### 👤 Profile

- Profile page for user-related information.
